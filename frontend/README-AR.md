# Lensee — النسخة العربية الكاملة

هذه الحزمة تحتوي على واجهة Lensee بعد استكمال وتحسين الترجمة العربية.

## أهم التعديلات

- العربية هي اللغة الافتراضية للمستخدم الجديد، مع استمرار دعم التبديل إلى الإنجليزية.
- ترجمة صفحات تسجيل الدخول، لوحة التحكم، الكتالوج، المخزون، CRM، العمليات، المدفوعات، التقارير، الجرد، التنبيهات، وإدارة المستخدمين.
- ترجمة النصوص الديناميكية مثل أعداد السجلات، الصفحات، رسائل النجاح، حالات العمليات، ورسائل التحقق.
- حفظ النص الإنجليزي الأصلي لكل عنصر لمنع تلف النص عند التبديل المتكرر بين اللغتين.
- تحسين كامل لاتجاه RTL للجداول، النماذج، الإشعارات، حقول كلمات المرور، والأزرار.

## الملفات الرئيسية المعدلة

- `app.js`
- `styles.css`
- `index.html`

## التشغيل

```bash
npm run build
```

في نشر Vercel يجب ضبط المتغير:

```text
LENSEE_API_BASE_URL=https://your-public-api.example.com
```
